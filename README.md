# MVP: отчет о проверке товарного знака

Настольное Python-приложение формирует DOCX-отчет по структуре предоставленного шаблона. Оно
открывается отдельным окном и не использует браузер, сайт или localhost. Карточки ФИПС заполняются
по ссылке автоматически, после чего все значения можно проверить и исправить.

## Возможности

- основные данные отчета и повторяемые классы МКТУ;
- шаблонные заключения: нет препятствий, есть препятствия, письма-согласия;
- редактируемый текст заключения с переносом правок и оформления в DOCX;
- пять уровней вероятности и несколько строк вероятности;
- повторяемые международные знаки, товарные знаки РФ и заявки;
- извлечение номера, дат, владельца/заявителя, классов и изображения с ФИПС;
- гиперссылка на ФИПС в номере регистрации или заявки;
- автоматический расчет пошлин с учетом классов и позиций сверх 10;
- формирование `.docx` без хранения истории отчетов.

На вкладке «Заключение» шаблонный текст можно исправить перед выгрузкой. Поддерживаются
жирный шрифт, курсив, выделенное предупреждение и буквенные списки. Кнопка
«Сформировать заново по шаблону» возвращает актуальный текст по данным отчета.

## Запуск

Требуется Python 3.10 или новее.

### Windows

Дважды щелкните `start_windows.bat`. При первом запуске будет создано виртуальное окружение и
установлены зависимости.

### macOS

В терминале один раз выполните:

```bash
chmod +x start_macos.command
```

Затем запускайте `start_macos.command` двойным щелчком или из терминала. Откроется отдельное окно
программы.

Готовую сборку macOS можно также запустить двойным щелчком по
`dist/Отчет по товарному знаку.app`. Она не требует запуска сервера.

## Сборка отдельного приложения

- macOS: запустите `build_macos.command`; результат появится в `dist` в формате `.app`.
- Windows: запустите `build_windows.bat`; результат появится в `dist` в формате `.exe`.

## Справочник МКТУ

Файл `data/nice_classes.json` содержит заполненные описания классов 01–45 из предоставленного
рабочего справочника. После выбора класса описание автоматически подставляется в форму и остается
доступным для ручной корректировки.

## Настройка пошлин

Ставки находятся в `src/trademark_report/fees.py` в структуре `FeeSchedule`.
